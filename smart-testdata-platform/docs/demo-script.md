# 演示脚本

## 演示前准备

1. 启动 MySQL：

```bash
docker compose up -d mysql
```

2. 配置环境变量：

```bash
cp .env.example .env
```

3. 启动后端：

```bash
cd backend
mvn spring-boot:run
```

4. 启动 AI 服务：

```bash
cd ai-service
python -m uvicorn app.main:app --reload --port 8000
```

5. 启动前端：

```bash
cd frontend
npm run dev
```

打开 `http://localhost:5173`。

## 演示流程

### 1. 注册登录

演示：注册新账号，登录进入工作台。

讲解：JWT 认证，未登录无法访问业务 API。

### 2. 创建项目

演示：创建一个测试项目。

讲解：项目作为数据源和任务的归属容器。

### 3. 添加数据源

演示：添加 MySQL 数据源，测试连接。

讲解：密码加密存储，连接使用动态连接池。

### 4. Schema 分析

演示：读取数据源 Schema，查看表、字段、主键、外键。

讲解：后端缓存 Schema，AI 服务基于真实结构生成计划。

### 5. AI 生成计划

演示：输入测试数据需求，生成测试数据计划。

讲解：Agent + LLM Router 调用 DeepSeek / Qwen，未配置 Key 时自动 Mock。

### 6. 测试数据生成

演示：按计划生成单表或多表测试数据。

讲解：多表关联、外键引用、字段生成器。

### 7. 隐私脱敏

演示：自动识别手机号、邮箱、姓名，执行脱敏。

讲解：生成数据在写入前完成脱敏。

### 8. 数据质量评估

演示：查看完整性、唯一性、一致性、合法性、隐私安全评分。

讲解：五项指标加权计算。

### 9. 数据导出

演示：导出 CSV、SQL、JSON。

讲解：导出内容基于脱敏后数据。

### 10. Agent 执行轨迹

演示：查看 Agent 每一步分析、计划、生成、脱敏、质量评估记录。

讲解：Agent 流程可追踪，便于定位问题。

## 时间建议

- 整体演示：10 到 15 分钟
- 核心流程：8 分钟
- Agent 和隐私脱敏亮点：3 分钟
- 提问互动：2 到 5 分钟
